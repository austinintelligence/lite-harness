# Security policy

Lite-Harness is pre-release software. Regular Docker provides useful local
containment but is not a hostile multi-tenant security boundary.

Report suspected vulnerabilities privately through GitHub's security advisory
form for `drperky20/lite-harness`. Do not open a public issue containing an
exploit, credential, private workspace data, or provider response.

Supported security updates currently target only the latest commit on the
default Lite branch. See `docs/THREAT_MODEL.md` for the intended trust model and
known exclusions.
